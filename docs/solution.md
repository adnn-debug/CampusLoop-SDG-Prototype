# Proposed Solution

CampusLoop is a digital campus problem-reporting and resolution platform.

## Student Flow

1. A student identifies a campus problem.
2. The student reports it through the website.
3. Relevant details and supporting evidence can be provided.
4. The report enters the administrative review process.
5. The student can track its current status.
6. Progress updates provide transparency.
7. When the issue is resolved, the student can submit feedback.

## Administrative Flow

1. Admin receives a submitted report.
2. Admin checks whether the report is valid.
3. The problem is categorized and processed.
4. Its status is updated during the resolution process.
5. The issue is marked as resolved when action is completed.
6. Student feedback helps evaluate whether further action is required.

## Core Principle

**Report → Review → Action → Resolution → Feedback**
