# Prototype Screenshots

Upload clean screenshots of the working CampusLoop prototype to this folder.

Recommended filenames:

- `home-page.png`
- `report-problem.png`
- `admin-dashboard.png`
- `problem-status.png`
- `feedback-panel.png`

Try to crop out unrelated browser tabs, bookmarks, notifications, account details, or any personal information.

Once the images are uploaded, the main README can display them directly using Markdown such as:

```md
![CampusLoop Home Page](screenshots/home-page.png)
![Report Problem](screenshots/report-problem.png)
![Admin Dashboard](screenshots/admin-dashboard.png)
![Problem Status](screenshots/problem-status.png)
![Feedback Panel](screenshots/feedback-panel.png)
```
